# PCGProfiler 已实现功能归档

更新时间：2026-04-14
适用项目：`F:\Unreal Projects\ElectricDreamsEnv\Plugins\PCGProfiler`

## 1. 运行与采集流程

### 1.1 手动命令能力
- `PCGProfiler.StartRun [RunName]`
- `PCGProfiler.EndRun`
- `PCGProfiler.ResetRun`
- `PCGProfiler.ExportJson [OptionalPath]`
- `PCGProfiler.IsRunIdle`
- `PCGProfiler.WaitForRunComplete [TimeoutSeconds] [PollIntervalSeconds]`
- `PCGProfiler.RunBatch [Iterations] [TimeoutSeconds] [PollIntervalSeconds]`

### 1.2 Tools 菜单能力
- `PCG Profiler One-Click Run`
- `PCG Profiler Run Batch x10`
- `PCG Profiler Run Batch...`（可输入次数）

### 1.3 一键流程（C++）
- `StartRun -> CleanupAllPCGComponents -> GenerateAllPCGComponents -> Tick等待 -> EndRun -> ExportJson`
- 采集完成后每轮导出 1 个 JSON。

### 1.4 批量流程（C++）
- 串行执行多轮 one-click。
- 支持固定冷却间隔（当前默认 3s）。
- 支持失败提前终止（超时/导出失败）。

## 2. 稳定性与一致性能力

### 2.1 批次稳定门槛
- 连续 idle tick 判定。
- `GetActivePCGComponentCount()==0` 参与判定。
- 组件总数稳定窗口判定（避免轮间动态变化直接开下一轮）。

### 2.2 World 锁定
- 批次开始锁定目标 world。
- 后续轮次优先使用锁定 world，降低 world 漂移导致的数据口径变化。

### 2.3 组件作用域锁定
- one-click 启动时记录组件快照（scope keys）。
- Harvest 仅采集锁定 world + 锁定组件集合，减少跨 world/跨组件污染。

### 2.4 Purge 模式
- 批跑默认启用 purge 清理（更慢但更稳）。

## 3. 统计指标能力

### 3.1 节点级时延统计
- `total/min/max/avg/stddev/cv/p50/p95`
- `call_count/sample_count`
- `first_seen_time_ms`

### 3.2 IO 规模统计（节点级）
- `input_count_*` / `output_count_*`
- `input_points_*` / `output_points_*`
- 已包含 `max/sum/last/avg/p95/cv`

### 3.3 线程与调度统计
- 节点级：`game_thread_ms/worker_thread_ms`、调用次数、比例。
- 运行级：`thread_load` 对象，含
  - 总量/占比
  - 分 phase 统计
  - timeline windows
  - 并发度分析（concurrency、worker_parallelism）
  - queue wait vs execution
  - 不均衡评分
  - top nodes by thread
  - thread jitter
  - scheduling bottlenecks
  - parallel_efficiency（含建议）

### 3.4 Cache 统计
- 节点级 cache hit/miss、miss reason、命中率。
- 运行级 `cache_analysis`：
  - graph cache hit/miss/hit rate
  - miss reason breakdown
  - per-run cache stats
  - cold vs hot start
  - invalidation propagation chain
  - parameter sensitivity report

### 3.5 规模/内存估算统计
- 节点级 `estimated_memory_bytes`、`memory_share`、`point_share`。
- `scale_summary`：总/峰值估算内存、按点数与估算内存 top 节点、按 phase/thread_group 聚合。
- 估算方法标记：`point_count_x_160_bytes`，置信度 `medium`。

### 3.6 稳定性统计
- 顶层 `stability`（run 级 CV 指标）。
- `node_stability_topn`。
- `cross_run_node_stats`（跨 run p50/p95）。

### 3.7 路径与贡献分析
- `critical_path_method` + `critical_path`。
- `link_contribution_graph`（边贡献）。
- `top_n`（by_total_ms / by_peak_ms）。

## 4. JSON 输出结构（已实现）

### 4.1 顶层主要字段
- `run_name`, `schema_version`, `engine_version`, `platform`, `build_config`
- `graph_name`, `component_name`, `map_name`
- `run_start_utc`, `run_end_utc`, `run_duration_ms`, `node_count`
- `nodes`, `events`
- `scale_summary`, `cache_analysis`, `thread_load`, `stability`
- `phase_buckets`, `top_n`, `node_stability_topn`, `cross_run_node_stats`
- `link_contribution_graph`, `critical_path_method`, `critical_path`

### 4.2 输出位置
- 默认：`Saved/Profiling/PCG/PCGProfiler_YYYYMMDD_HHMMSS.json`
- 支持相对/绝对路径参数导出。
