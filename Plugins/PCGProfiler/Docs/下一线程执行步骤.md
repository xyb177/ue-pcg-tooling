# UE5.7 PCG Profiler 下一线程执行步骤

更新时间：2026-04-09
目标：完成大规模真实关卡下统计稳定性/性能回归基准，并产出中文报告。

## 0. 前置检查
1. 清理残留进程
```powershell
Get-Process -Name UnrealEditor-Cmd -ErrorAction SilentlyContinue | Stop-Process -Force
```

2. 确认脚本存在
- `F:\UnrealEngine-5.7.3-release\Plugins\PCGProfiler\Scripts\Run-PCGProfilerBenchmark.ps1`

## 1. 快速验证（2图 x 2轮）
```powershell
& "F:\UnrealEngine-5.7.3-release\Plugins\PCGProfiler\Scripts\Run-PCGProfilerBenchmark.ps1" -IterationsPerMap 2 -TimeoutPerRunMinutes 10 -RetryCount 1
```

验收：
1. 生成 `基准结果汇总_*.json`
2. 生成 `大规模真实关卡_统计稳定性性能回归报告_*.md`
3. 报告中每张图 `sample_count >= 2`

## 2. 正式基准（2图 x 5轮）
```powershell
& "F:\UnrealEngine-5.7.3-release\Plugins\PCGProfiler\Scripts\Run-PCGProfilerBenchmark.ps1" -IterationsPerMap 5 -TimeoutPerRunMinutes 12 -RetryCount 1
```

验收：
1. 报告文件生成成功
2. 每张图 `sample_count >= 5`（若有失败样本，报告需列明原因）
3. 报告包含：Duration Mean/P95/CV、GT Mean、Worker Mean、并行效率均值、稳定性结论

## 3. 交付归档
1. 将最新两份报告路径写回：
- `Plugins/PCGProfiler/Docs/已实现功能归档.md`（新增“基准报告”章节）
- 或新增 `Plugins/PCGProfiler/Docs/基准报告索引.md`

2. 在回复中给出：
- 执行命令

## 风险与处理
1. 若单轮超时：
- 保留失败样本记录，继续下一轮
- 适当调大 `-TimeoutPerRunMinutes` 到 15

2. 若无 JSON 导出：
- 检查插件加载参数 `-PLUGIN=`
- 检查 `ExecCmds` 执行顺序与日志

3. 若进程卡住：
- 终止残留 `UnrealEditor-Cmd`
- 从“快速验证”重新起跑
