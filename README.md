# Unreal Engine 项目作品集

这是一个用于展示 Unreal Engine 开发能力的作品集仓库。

`main` 分支不放具体项目代码，仅作为总入口和索引页。  
实际项目分别放在不同的 feature 分支中，每个分支对应一个独立主题：

- `feature/runtime-spawn-budget`：运行时调度、对象池、性能指标与自动化测试
- `feature/blueprint-patch`：Blueprint 受控编辑流程、校验与回滚
- `feature/pcg-profiler`：PCG 性能分析与报告工具
- `feature/pcg-circle-legacy`：CircleComponent 与 PCG 互操作探索


## 仓库内容

- Unreal Engine C++ 与插件开发
- 编辑器与工具链开发
- 运行时性能工程
- 自动化测试与回归验证
